# CS203A – Data Structures

Data Structures is an undergraduate course that studies how data can be **organized, represented, manipulated, and processed efficiently**.

This course approaches data structures from multiple perspectives:

> **Discrete Mathematics → Data Structures → Algorithms → C++ Implementation → Practice & Evaluation**

Students will study the theoretical foundations of data structures, implement them in C++, apply algorithms to manipulate and analyze the structures, and verify their implementations through programming exercises and automated testing.

## Course Description

This course introduces fundamental data structures and their associated algorithms through the integration of **discrete mathematics, C++ programming, algorithm analysis, and practical implementation**.

Topics include arrays, linked lists, stacks, queues, trees, heaps, graphs, hashing, searching, and sorting.

For each major topic, students will explore the underlying mathematical concepts, investigate how the structure can be represented in a computer, study fundamental algorithms operating on the structure, and implement the corresponding data structures and algorithms in C++.

Programming assignments and practice exercises emphasize correctness, computational efficiency, and implementation skills. Automated testing with **GitHub Actions** will be used in selected programming assignments to provide systematic feedback on program correctness.

AI-assisted learning will also be incorporated into selected learning activities. Students are expected to understand, verify, and take responsibility for any code or explanation produced with the assistance of AI tools.

## Learning Approach

Each major topic will be explored from several connected perspectives:

| Perspective                   | Guiding Question                                                                     |
| ----------------------------- | ------------------------------------------------------------------------------------ |
| **Discrete Mathematics**      | What mathematical concepts and properties define the structure?                      |
| **Data Structure**            | How should the data and their relationships be represented?                          |
| **Algorithms**                | What operations and algorithms can be applied to the structure?                      |
| **C++ Programming**           | How can the structure and algorithms be implemented correctly?                       |
| **Practice & Implementation** | Can the implementation solve practical problems and pass systematic tests?           |
| **AI-Assisted Learning**      | How can AI assist learning, implementation, debugging, and verification responsibly? |

The goal is not only to learn individual data structures, but also to understand the connection between **abstract concepts and executable programs**.

## Learning Materials

### 📖 Study Notes

[Study Notes](StudyNote/README.md) provide supplementary materials for each data structure and algorithm covered in the course.

The notes may include:

* concepts and definitions
* mathematical foundations
* data representations
* algorithm explanations
* complexity analysis
* implementation examples
* worked examples and exercises

Students are encouraged to use the notes together with lectures and programming practice.

### Programming Practice

[Practice Problems](Code/README.md) provide hands-on exercises for implementing and experimenting with data structures and algorithms.

Practice activities may include:

* implementing fundamental operations
* observing memory behavior
* comparing alternative implementations
* analyzing algorithm performance
* solving small programming problems

Students are encouraged to experiment with the code rather than simply reproduce the provided examples.

### Programming Assignments

[Programming Assignments](Assignment/README.md) reinforce the connection between data structures, algorithms, and C++ implementation.

Assignments may require students to:

* implement a specified data structure
* implement fundamental operations
* apply a simple algorithm using the structure
* analyze computational complexity
* test and verify the implementation
* document design decisions and observations

Selected assignments will use **GitHub Actions** to automatically compile and test submitted programs against instructor-designed test cases.

Passing automated tests demonstrates program correctness for the tested cases but does not replace the student's responsibility to understand and explain the implementation.

### Quizzes

[Quizzes](Quiz/README.md) are short assessments used throughout the semester to reinforce important concepts and encourage continuous learning.

Questions may assess:

* conceptual understanding
* data structure operations
* code tracing
* complexity analysis
* algorithm behavior
* selection of appropriate data structures or algorithms

### Visualizations and Animations

[Animations](Animation/README.md) provide interactive demonstrations of selected data structures and algorithms.

Visualizations are used to help connect abstract concepts with the dynamic behavior of algorithms such as tree traversal, graph traversal, searching, and sorting.

### Utilities

[Utility Tools](Utility/README.md) provide scripts and supporting tools for experiments, visualization, debugging, and performance analysis.

## Programming and Evaluation Workflow

Programming activities in this course will increasingly follow a software-development workflow:

**Understand → Design → Implement → Test → Debug → Verify → Reflect**

Students should not consider a program complete simply because it compiles.

A correct implementation should:

* satisfy the required interface
* produce correct results
* handle specified boundary cases
* pass the provided automated tests
* use the intended data structure and algorithm
* be understandable and maintainable

Git and GitHub will be used to maintain programming assignments and learning progress throughout the semester.

---

## AI-Assisted Learning

AI tools can be useful for explaining concepts, exploring alternative implementations, debugging programs, and reviewing code. However, generated answers and programs may contain conceptual errors, inefficient algorithms, or incorrect implementations.

Therefore:

> **AI output should be treated as a hypothesis to be examined, not as an answer to be trusted automatically.**

Students remain responsible for understanding, testing, verifying, and explaining their submitted work.

Detailed AI usage guidelines for assignments and assessments will be provided in the [Course Syllabus](Syllabus.md).
