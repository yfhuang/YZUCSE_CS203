## Course Description

This course introduces fundamental data structures and their associated algorithms for undergraduate students.

Topics include arrays, linked lists, stacks, queues, trees, binary search trees, heaps, graphs, hashing, searching, sorting, and selected advanced data structures.

Each topic will be studied from several connected perspectives:

* discrete mathematics
* data representation
* algorithm design
* C++ implementation
* time and space complexity
* programming practice
* testing and evaluation

Emphasis is placed on understanding how abstract mathematical concepts can be represented using appropriate data structures, how algorithms operate on these structures, and how the resulting implementations can be tested and evaluated.

Programming assignments will require students to implement selected data structures and fundamental algorithms in C or C++. Selected assignments will use GitHub Actions and instructor-provided test cases to evaluate compilation, correctness, and selected boundary conditions.

The course also introduces responsible AI-assisted learning. AI tools may be used only in accordance with the policies and instructions provided for each learning activity. Students remain responsible for understanding, testing, verifying, and explaining all submitted work.

## Course Learning Approach

The course follows the general learning sequence:

> **Discrete Mathematics → Data Representation → Algorithms → C++ Implementation → Practice and Evaluation**

For each major topic, students will consider the following questions:

| Perspective                 | Guiding Question                                                               |
| --------------------------- | ------------------------------------------------------------------------------ |
| **Discrete Mathematics**    | What mathematical concepts, relations, or properties define the structure?     |
| **Data Representation**     | How can the information and relationships be represented in memory?            |
| **Algorithms**              | What operations and algorithms can be applied to the structure?                |
| **C++ Programming**         | How can the data structure and algorithms be implemented correctly?            |
| **Complexity Analysis**     | What are the time and space requirements of the operations?                    |
| **Practice and Evaluation** | How can correctness and performance be evaluated through test cases?           |
| **AI-Assisted Learning**    | How can AI tools support explanation, debugging, and verification responsibly? |

The intended learning process is:

> **Understand → Represent → Design → Implement → Analyze → Test → Reflect**

## Learning Outcomes

Upon successful completion of this course, students will be able to:

1. Explain the concepts, properties, and applications of fundamental data structures.
2. Describe the mathematical foundations associated with common data structures.
3. Represent abstract relationships using appropriate data structures.
4. Implement fundamental data structures and their operations in C or C++.
5. Apply basic algorithms to manipulate and process structured data.
6. Analyze the time and space complexity of data structure operations and algorithms.
7. Compare alternative data structures and algorithms for a given problem.
8. Select appropriate data structures to solve computational problems.
9. Design test cases to evaluate implementation correctness and boundary conditions.
10. Use Git and GitHub to maintain programming assignments and learning progress.
11. Interpret automated testing results and revise implementations accordingly.
12. Use AI tools responsibly for learning, explanation, debugging, and verification when permitted.
13. Explain and defend the design and correctness of submitted programs.

## Programming Assignments

Programming assignments are designed to connect data structure concepts, algorithms, implementation, and testing.

Assignments may require students to:

1. implement a specified data structure
2. implement fundamental operations on the structure
3. apply a simple algorithm using the structure
4. analyze time and space complexity
5. design additional test cases
6. document implementation decisions
7. maintain meaningful Git commit history
8. evaluate and revise the implementation using automated feedback

The primary purpose of the programming assignments is to evaluate students' understanding and implementation of data structures rather than advanced competitive-programming techniques.

Each assignment will define:

* required files and directory structure
* required classes, functions, or interfaces
* input and output format
* required data structure
* required algorithm
* compilation requirements
* evaluation criteria
* submission deadline

---

## GitHub and Automated Evaluation

Selected programming assignments will use GitHub and GitHub Actions.

Automated evaluation may include:

* repository structure checking
* source file checking
* compilation
* unit testing
* input/output comparison
* normal test cases
* boundary test cases
* selected stress tests
* basic runtime checks

Instructor-provided test cases may include visible and hidden tests.

Passing all automated tests indicates that the submitted implementation satisfies the tested conditions. It does not guarantee correctness for every possible input.

Students are expected to:

* compile and test programs locally before submission
* read automated evaluation results carefully
* identify the cause of failed tests
* revise and verify the implementation
* design additional tests independently

A program should not be considered complete merely because it compiles or passes a limited number of tests.

### Academic Integrity

All submitted work must reflect the student's own understanding and effort.

The following activities are prohibited:

* plagiarism
* unauthorized copying
* submitting another person's work
* allowing another person to submit copied work
* falsifying programming or learning records
* submitting code that the student cannot explain
* using unauthorized resources during quizzes or examinations

Collaboration may be allowed for selected activities, but each student must submit their own work unless a group submission is explicitly required.

Students should clearly acknowledge permitted external resources when required.

---

### AI-Assisted Learning Policy

AI tools may be used only when permitted by the instructions for a specific activity.

Permitted uses may include:

* asking for explanations of concepts
* generating additional examples
* identifying possible compilation errors
* suggesting debugging directions
* reviewing documentation
* comparing implementation approaches
* generating test ideas

Unless specifically permitted, students must not directly submit AI-generated code, answers, analyses, or documentation as their own work.

When AI assistance is permitted, students remain responsible for:

* understanding the generated content
* verifying factual and technical correctness
* testing generated code
* correcting errors
* ensuring compliance with assignment requirements
* explaining the final implementation
* disclosing AI use when required

AI-generated output should be treated as a proposal to be examined rather than an answer to be accepted automatically.

AI assistance is prohibited during quizzes, the midterm examination, and the final examination unless explicitly authorized.

---

### Late Submission

Late submissions will be subject to grade deduction.

The deduction policy may vary according to the assignment and will be described in the corresponding assignment instructions.

Exceptions may be considered only when:

Technical problems caused by lack of backup, incomplete uploads, incorrect repository settings, or failure to verify the submission are normally not considered valid reasons.
